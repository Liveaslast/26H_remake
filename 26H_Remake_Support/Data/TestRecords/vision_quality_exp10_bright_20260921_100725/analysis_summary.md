# 亮光动态视觉质量分析（exp10 / 1 ms）

## 条件

- 数据：`vision_quality_exp10_bright_20260921_100725/motion_probe.csv`
- 曝光：手动，`exposure_time_absolute=10`，即 1 ms
- 动态曝光帧率：关闭
- 正式链路：HailoRT、1280×720 MJPG、60 fps
- 对比基线：`vision_quality_exp10_20260921_094539/motion_probe.csv`

## 结果

| 指标 | 暗场基线 | 提高光照后 |
|---|---:|---:|
| 实际采集时长 | 59.187 s | 19.270 s |
| 主循环频率 | 59.90 Hz | 58.38 Hz |
| 当帧测量有效率 | 40.03% | 100.00% |
| 有效测量频率 | 23.98 Hz | 58.38 Hz |
| 追踪有效率 | 86.35% | 99.91% |
| 有效检测置信度均值 | 0.5025 | 0.9010 |
| 有效检测置信度 P05 | 0.2747 | 0.8976 |
| 测量失效段数 | 593 | 0 |
| 最长测量失效 | 798.6 ms | 0 ms |
| 推理耗时 P95 | 5.27 ms | 6.26 ms |
| 处理耗时 P95 | 16.72 ms | 19.55 ms |
| 相邻测量推算速度 P95 | 13.88 cm/s | 14.93 cm/s |
| 相邻测量推算最大速度 | 19.01 cm/s | 22.37 cm/s |

亮光测试共 1125 帧，除首帧等待连续命中确认外，其余 1124 帧全部为 `ok`；没有 `short-prediction` 或 `ball-not-detected`。坐标运动范围约 14.97 cm。最大相邻位置变化对应 22.37 cm/s，不属于数厘米级单帧乱跳。

## 结论

暗场动态漏检的主因是照明不足，不是 HailoRT 算力、相机帧率或坐标链路。维持 1 ms 曝光并提高现场光照后，动态识别连续性已经达到本轮测试的理想状态。当前没有证据支持立即把曝光提高到 2 ms；应先用这一照明条件测试 Task1。若现场光照无法稳定保持，再采集 2 ms 数据并与本结果比较运动模糊和坐标跳变。

正式视觉和控制配置未作修改。
