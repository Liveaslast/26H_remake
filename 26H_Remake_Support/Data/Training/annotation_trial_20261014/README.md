# Ball annotation trial

Six manual trial boxes on existing 640x128 training-input images. YOLO labels are class 0 in normalized `x_center y_center width height` format. Files are named by angle and original image stem to avoid collisions. Original images and labels remain unchanged.

Preview boxes include the visibly dark ball and some soft edge/shadow; compare with the original labels before using these for training. This trial is for visual review, not a replacement dataset.
