# 26H_Remake｜钢球平衡系统

钢球平衡系统复刻工程，使用树莓派视觉测量小球状态，由 STM32 进行状态估计、任务执行和电机闭环控制。仓库包含上下位机程序，以及标定、训练、采集和分析工具。

## 系统组成

| 工程 | 运行位置 | 负责什么 |
|---|---|---|
| `26H_Remake_Raspderry` | 树莓派 | 读取图像、匹配电机角度、检测与跟踪小球，向 MCU 发送视觉数据和任务请求 |
| `26H_Remake_DJC` | STM32 | 接收请求、估计小球位置与速度、执行球杆任务和电机控制，回传遥测 |
| `26H_Remake_Support` | 电脑及树莓派离线工具环境 | 制作标定与训练资料，采集和分析实验数据；不参与正式控制循环 |

相机图像经 Pi 处理得到小球状态，通过串口交给 MCU；MCU 执行控制并返回电机角度等遥测。Pi 将角度与图像时刻匹配，用于后续视觉测量，形成完整反馈链。

## 通过Pi进行调试（PS:目前也做好了串口调试的接口，也可以用串口进行同样业务的调试）

- **RUN 模式**：执行正式任务，目前 task 1 为小球位置序列任务。
- **TUNING 模式**：配置并执行调参任务，目前 task 1 为固定球速测试。
- 两种模式的任务号独立，task 0 均用于初始化；模式应答与任务执行结果分别确认。
- 可选记录视觉结果、实际发包和 MCU 控制遥测，用于离线分析。

代码按业务职责组织：视觉输出最终小球状态，通信负责传输，任务负责目标与阶段，控制器负责控制计算。各部分通过明确接口连接；整体关系见 [系统架构](ARCHITECTURE.md)。

## 使用与开发

按需要进入对应工程，各 README 维护自己的环境要求、运行命令和源码入口：

- [树莓派程序](26H_Remake_Raspderry/README.md)：视觉与通信启动、任务交互、模型和标定要求。
- [STM32 固件](26H_Remake_DJC/README.md)：编译、RTOS 任务、控制组件与串口调试。
- [资料与实验工具](26H_Remake_Support/README.md)：标定训练、数据采集和分析。

上下位机需使用配套协议版本。当前源码、离线检查与历史实验记录分别提供不同证据，不能据此认定设备已部署或完成实机验证。

**Pi 退出或 CSV 采集结束不会自动停止 MCU 电机控制。实机操作需另行确认停止方式。**
